# Section residents and toolkit

Pip is now an eight-legged spider supported by silk in a builder-section corner web. Gravity is countered by damped silk tension. Timed resting, descent, return and cursor-retreat states stay near its physical home. Spool is a butterfly with separate fore/hind wings, veins, antennae and landing legs. Flower perches sit beneath the portrait and in a contact corner. It rests on a flower, chooses a new visit, may briefly investigate a distant pointer, or retreats from a close one. Flight uses bounded steering, gravity and wing lift. Both use document coordinates, so scrolling leaves them in their sections; offscreen habitats stop rendering. They are reactive simulated personalities, not AI agents. Touch-only and reduced-motion modes remain quiet, and the global hide control still works.

The toolkit contains 63 distinct technologies across five browsable categories. Sources are project tech arrays, listed skills, explicit project architecture and actual dependencies used by this portfolio. Expanding a tool shows its evidence. Portfolio dependencies are labelled as such, not presented as independent claims of expertise. Category buttons, previous/next buttons, native horizontal swipe/scroll, keyboard arrows/Home/End and reduced-motion behavior are supported. No autoplay hides names while reading.

Verification: 47 unit tests, 52 existing site checks, focused browser checks for anchored habitats and toolkit controls, and eight responsive theme/viewport combinations. Hero and 3D story markup remain unchanged. Screenshots remain local; the verification report records the tested behaviors.

# Reference investigation and second implementation

Target: https://bajkamalsingh.me/ . Examined public shipped HTML, its three inline JavaScript blocks, live desktop rendering, the origin sequence and the metro entrance. The source was inspected for behavior, not transplanted into this repository. Original branding, media, copy and metro drawings remain the reference author's.

REA evidence `ev_cd20a3638b1b19f953896c0f3a41c36c05bf5fa096908a02b2ea2e2819c36ac1` covers static analysis of the extracted inline JavaScript. Its identity and limitations are retained in rea-summary.json. Full local evidence is /tmp/reference-rea-evidence.json. REA MCP registration was aligned but its tools were unavailable to the active agent; the installed CLI provided static analysis. Native decompilers are irrelevant to this HTML/JavaScript target.

The live reference combines a dominant hero wordmark and video backdrop, a long CSS perspective notebook sequence, a persistent chapter dock and progress ribbon, physical paper treatments, dossier cards, a gallery and a metro project selector. It is principally DOM/CSS and GSAP, not a single Three.js environment. Its scripts load GSAP, ScrollTrigger, Draggable, Lenis and Tone. Static analysis cannot establish every interactive runtime outcome; screenshots corroborate arrival, origin and the metro before/after its entrance.

The origin timeline uses scrub 2.2 and transformed notebook scale, rotation and camera-like translation. Live ScrollTrigger inspection showed a long origin interval, an experience pin of 600px and a metro pin of 1200px at the observed viewport. The metro entry separates two door panels over 1.5s. Project navigation changes a translated transit world with a 3.5s sine.inOut transition and a short rattle. These are source observations, not prescriptions to copy their durations blindly.

The first local implementation had a conventional split hero, a backdrop-sized 3D scene, disconnected camera pose changes, and largely still downstream sections. It did not reproduce the reference's sustained visual staging. The second pass keeps the original Build Room identity but makes typography dominant, expands the canvas across the stage, uses transparent live rendering over a workshop grid, follows a continuous camera path through brief/build/inspection, moves trays along a single axis, introduces a chapter dock, and gives papers, portraits, shelf projects and contact artwork a physical settling motion. Reading copy remains available and reduced-motion mode removes scroll transforms.

Native scroll is retained. No loader gate, forced sound, custom cursor or copied metro illustration is introduced. Inspection remains a disclosure and case-study navigation remains ordinary HTML links. A discovered query navigation bug was fixed: project selection preserves the chapter hash so it cannot unexpectedly return the visitor to the top.

Review coverage is bounded: the reference's every individual gallery asset and audio event were not exhaustively exercised. The implementation recreates the observed interaction principles with original code and assets, rather than claiming an exact source clone.

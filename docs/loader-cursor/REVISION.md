# Original workshop opening

Replaces the reference reconstruction with an original, staggered Bricolage composition: “A little curiosity. A lot of making.” The surface, ink, muted text and rules inherit the site's theme tokens, in both light and dark modes. The reference's blue curtain, black bar, borrowed statement and counter typography are removed.

Pip and Spool are drawn using the existing creature renderer on a separate intro canvas above the curtain. The spider hangs from its web while the butterfly flies near a flower and reacts to a nearby pointer. They appear on phones as well as desktops. The canvas animation is disposed with the intro, respects reduced motion, and does not affect the creatures' existing habitats further down the page.

The counter remains a short introduction clock rather than measured network progress. Skip, Escape, Tab, deep-link bypass and native-cursor accessibility fallbacks remain available. The original reference notes and first verification captures describe the previous iteration; the latest browser report checks the site's sage/ink palette and Bricolage typography.

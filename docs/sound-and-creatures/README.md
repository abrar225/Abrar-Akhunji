# Portfolio sound and creatures

The restored hero and 3D story remain unchanged. Pip (a cautious seed) and Spool (a curious moth) use original bounded steering and pointer avoidance. They never intercept input and stop for reduced motion, touch-only devices, hidden tabs or the hide control. The signature has stronger spring forces and an adjustable Feel control. The cursor is centered on the pointer; its label flips at viewport edges.

The optional sound room uses the real Flow Music Producer track “Little Useful Things,” edited into a 60-second circular loop, and fourteen effects authored in Flow Music Spaces. Flow's embedded ZIP download did not complete. Its generated code was exported from the code view, reviewed and rendered locally without changing the DSP, using native OfflineAudioContext and the Flow WAV/ZIP encoders. The effects were then peak-matched for a quiet web mix. This distinction is recorded in provenance.json and the public audio manifest. The complete generated source, production prompts and rendering/processing scripts are retained for reproducibility. No test-fixture audio is shipped.

Sound starts only after explicit opt-in. Music and effects have independent controls. Music ducks during narration and the city reveal. Every occupied contribution building receives a cue at its actual growth threshold, with pitch and stereo variation; replay resets the cycle. Hidden tabs suspend the shared context. River, signature, creatures, navigation, project selection and article sections use the same collection.

Verification: 46 unit checks; fifteen real audio files decoded and checked for finite, non-silent output, matching hashes, bounded peaks and silent effect tails; browser tests cover real audio opt-in, volume, city replay, visibility, narrator ducking, cursor edges, creatures, signature, eight responsive theme/viewport combinations and WebKit. Reports are in verification/. Fixture-report.json is an earlier controller-only test and is explicitly marked as such. Physical speaker/headphone listening quality was not verified by the agent.

The site target is the existing abrarakhunji.com static Hostinger website. Deployment uses the connected Hostinger deploy operation. Research screenshots and unrelated reference mirrors remain local; application source, required assets, tests and the audio provenance are included in Git.

## What the document actually asks designers to learn

The controlling idea is to choose a personal story and visual language before asking tools to implement it. Physical objects should guide attention and make the actual work easier to explore. The author repeatedly qualifies the guidance as personal experience, not universal rules. The creative concepts are alternatives; the text does not require combining a silhouette, notebook, Metro, pin board, vending machine, radio, folder, room, wallet and timing game into one portfolio.

The document's strongest practical constraints are direct access to the best work, arbitrary access to later projects without repeated interactions, a short honest introduction, optional discovery for secondary work, a quiet contact ending, and a deliberate balance between visual detail and load. It explicitly identifies mobile layout and accessibility as failings in the reference implementation. Those failings should be corrected in an adaptation, not copied.

## Complete concept inventory and disposition

The hero's silhouette, smoke, blue palette and quote ribbon are a cohesive identity for the reference author. They are not universal requirements. The unbuilt dwell-time popup is a bonus thought with no observed runtime status. It could distract from contact and is unnecessary here.

The diary controls attention while personal stickers add identity. Transfer those functions, not the notebook itself. A physical brief or a restrained sequence can serve the same purpose. The Metro is deliberately locally relatable and was simplified when buildings, street scenes and cafes became clutter. Transfer continuity and familiar project navigation while choosing a different subject-specific object.

The pin board, coin-operated vending machine, folder, frequency-tuned radio, illustrated room, timing game, wallet and scratch interaction were rejected or unfinished alternatives. Reasons vary: thematic mismatch, academic appearance, animation complexity, weak mobile behavior, repeated actions, voiceover needs, illustration skill and insufficient creative satisfaction. Their inclusion in the guide is not an instruction to implement every interaction. Pages 5–9 contain visual evidence of these abandoned drafts rather than specifications of the live website.

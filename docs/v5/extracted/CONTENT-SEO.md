## Runtime contracts

[main.jsx](../../../src/main.jsx) mounts the main app with React Router and Helmet. [App.jsx](../../../src/App.jsx) owns route selection, route-module loading, recovery, route-change focus and hash handling for asynchronously mounted content. [useTheme.js](../../../src/lib/useTheme.js) keeps the localStorage `theme` contract and dispatches `themechange` to subscribers. [BlogPost](../../../src/pages/BlogPost.jsx) retains a separate state for unrecoverable slug lookup, content loading and retryable content failure. The article reader uses the browser for narration, share/clipboard, bookmarks and local feedback.

The only contact-related form markup in the shell is a hidden WebMCP GET annotation targeting `/contact/`. The companion hidden search annotation targets `/blog/`. The [registration script](../../../index.html) exposes corresponding `get_contact_info` and `search_content` tools when `navigator.modelContext` supports them. No analytics script or event endpoint was found in the current browser entry points or route sources. The repository alone does not establish whether hosting infrastructure collects traffic logs or injects analytics.

# V5 sources and reference observations

Reviewed on 27 November 2026. The live-reference observations below come from desktop Chromium in Ego Browser using wheel and pointer input and the visible controls. The contact sheets are local research evidence. Interaction observations apply to the states sampled. Public case studies and documentation establish implementation details where applicable.

The A24 and Carter examples rely on wheel input for an interactive gallery. Their useful common property is continuity from one stable state to another. V5’s literal reverse experiment instead retains native page travel and tests whether the initial position, direct links and recovery remain intelligible. Cuetone and Lusion support a strong phase change from active imagery to calm copy, which gives the layered divider a narrative job.

I4, the requested GitHub animation profile, was unspecified. I5, the optional personal award entries, was unspecified. None of the examples above stand in for these inputs.
